# EVAZ · Eletro & Casa

Repositório oficial do site institucional e vitrine da **EVAZ** ([evaz.com.br](https://evaz.com.br)).

## 🚀 Deploy Contínuo (CI/CD)
Este repositório está integrado ao **Cloudflare Pages**. 
Qualquer `git push` na branch `main` dispara o deploy automático para produção em tempo real no domínio oficial [evaz.com.br](https://evaz.com.br).

## 📁 Estrutura
- `index.html`: Página principal e vitrine de produtos
- `assets/`: Identidade visual, mídias, banners e vetores
- `politica-de-privacidade.html`: Política de Privacidade (LGPD)
- `termos-de-uso.html`: Termos de Uso
- `_redirects`: Regras de rota do Cloudflare Pages
- `robots.txt` & `sitemap.xml`: Indexação para buscadores (Google, Bing)
